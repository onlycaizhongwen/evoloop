Web UI 任务模板增强预览

把最近新增的模板预览、推荐标签、最近运行状态、状态色和直接运行入口做成静态页面，方便直观看效果。

版本：2026-05-26

当前首页体验目标

少配置、少手写、能直接跑

用户进入首页后，可以先看模板能力和最近结果，再选择套用模板或直接运行。

本页面是静态预览 按钮不可真正提交任务；真实入口在 Web UI 首页。

本次增强内容

01 模板配置预览

卡片直接展示 backend、agent、preset、paths、checks。

02 推荐标签

展示 Default、Recommended、Docker、Local、Demo。

03 最近运行

展示模板最近一次 Job 的状态和 run_id。

04 直接运行

卡片按钮直接使用白名单模板创建 Job。

直接运行链路

1

点击模板卡片的直接运行

页面提交 template_id 到 /templates/run。

2

后端读取白名单模板

只允许使用 registry 中已有模板，不执行用户自定义模板。

3

生成 task JSON 并启动 Job

复用普通表单同一条创建任务逻辑，避免行为分叉。

4

跳转 Job 状态页

用户可以继续查看进度、启动配置、运行结果和 Docker 证据。
